# Fichiers de téléchargement

Les fichiers binaires ne sont plus suivis dans le dépôt afin de simplifier les mises à jour GitHub.

- **BTS SISR** : ajoutez ici `bts-sisr-parcours.pdf` (non versionnée) ou hébergez le PDF sur un stockage externe et mettez à jour le bouton de téléchargement dans `index.html`.
- **Tableau de synthèse** : ajoutez ici `tableau-synthese.xlsx` (non versionné) ou pointez le bouton vers votre fichier officiel hébergé en ligne.

Les boutons de téléchargement actuels génèrent des fichiers texte temporaires pour éviter l’ajout de binaires. Remplacez-les lorsque vos documents finaux sont prêts.
